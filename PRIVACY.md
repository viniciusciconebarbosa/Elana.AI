# Privacy Policy / Política de Privacidade

**Last Updated / Última Atualização:** June 08, 2026 / 08 de Junho de 2026

---

## English

### 1. Introduction
Elana AI ("we", "our", or "the software") is an open-source personal AI assistant client. We respect your privacy and are committed to protecting any data processed through our application.

### 2. Information Collection and Use
Elana AI is designed as a direct-connection client application. 
*   **No Developer Data Harvesting:** We do not collect, monitor, store, or sell any of your personal data, chat history, system prompts, or API keys.
*   **Local and Personal Database Storage:** Your chats, user profiles, and configuration settings are stored locally on your device or within your personal Supabase database instance, which is fully controlled and owned by you.
*   **Third-Party AI API Services:** To generate AI responses, the application transmits your chat messages and system prompts directly to the AI providers (such as OpenAI, Google Gemini, Anthropic, or others) using the API keys you provide. This data transmission is subject to the respective privacy policies of those third-party AI providers.

### 3. Security
Your API keys and database connection strings are stored securely in your local application environment or your personal database. We do not have access to these credentials.

### 4. Open Source Transparency
Since Elana AI is open-source, you can inspect the entire source code to verify how data is handled at: [GitHub Repository](https://github.com/viniciusciconebarbosa/Elana.AI).

## Português

### 1. Introdução
O Elana AI ("nós", "nosso" ou "o software") é um cliente de assistência pessoal de inteligência artificial de código aberto. Respeitamos a sua privacidade e estamos empenhados em proteger quaisquer dados processados através da nossa aplicação.

### 2. Coleta e Uso de Informações
O Elana AI foi projetado como uma aplicação de conexão direta.
*   **Sem Coleta pelo Desenvolvedor:** Nós não coletamos, monitoramos, armazenamos ou vendemos nenhum de seus dados pessoais, histórico de chat, prompts do sistema ou chaves de API.
*   **Armazenamento Local e Pessoal:** Seus chats, perfis de usuário e configurações de preferência são armazenados localmente no seu dispositivo ou na sua própria instância do banco de dados Supabase, a qual é totalmente controlada e de propriedade sua.
*   **Serviços de API de IA de Terceiros:** Para gerar as respostas da inteligência artificial, o aplicativo transmite suas mensagens de chat e prompts do sistema diretamente para os provedores de IA (como OpenAI, Google Gemini, Anthropic ou outros) utilizando as chaves de API fornecidas por você. Essa transmissão de dados está sujeita às políticas de privacidade de cada respectivo provedor de IA.

### 3. Segurança
Suas chaves de API e strings de conexão com o banco de dados são armazenadas de forma segura no ambiente local do seu aplicativo ou no seu banco de dados pessoal. Nós não temos acesso a essas credenciais.

### 4. Transparência de Código Aberto
Como o Elana AI é de código aberto, você pode inspecionar todo o código-fonte para verificar como os dados são gerenciados em nosso repositório oficial: [Repositório no GitHub](https://github.com/viniciusciconebarbosa/Elana.AI).
